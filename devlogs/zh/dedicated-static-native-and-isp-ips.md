# 什么是独享静态原生 IP？什么又是 ISP IP？

[English](../en/dedicated-static-native-and-isp-ips.md)

你买到的 IP，可能已经转了好几手：大公司把地址租给服务商，服务商再批发给下一家，最后才卖到你手里。收你钱的商家，未必就是实际提供网络的公司。“独享”“静态”“原生”和“ISP IP”这些说法，要放在这条转售链里看。

## 一个 IP 是怎样到你手里的？

IP 地址由专门的机构分配和登记，负责各个区域的机构叫 **RIR**，可以理解为号码管理机构。电信运营商、云服务商等公司取得一批地址后，可以自己用，也可以租给别人。这一批地址通常称为一个**地址段**，有的是通过分配获得的，有的是从其他公司受让或租来的。

服务商拿到这些 IP 后，可以随服务器一起出租，也可以提供代理服务。**代理**就是替你访问网站的中间站：你通过它打开店铺后台，网站通常看到的是代理的 IP，也就是**出口 IP**，有点像来电显示上的号码。

这门生意也有批发和零售。服务商可以直接卖给用户，也可以批发给下一家，由下一家继续转售：

地址持有者 → 网络服务商 → 批发商 → 转售商 → 最终用户

有些 IP 只经过一两层，有些则转手多次。对普通用户来说，“买 IP”通常是付费租用，退租后，服务商可以再分配给别人。

## 独享：只给你一个人用

独享 IP 指的是在约定的服务期间，这个出口地址只供你使用，不同时分配给其他客户。

有自己的代理账号和密码，不代表 IP 就是独享的。就像公司员工各有分机，对外打电话时却可能显示同一个总机号码。

这件事很难独立核实。公开查询工具能查到登记公司和部分历史记录，却查不到服务商把地址分给了哪些客户。所以，独享承诺主要还是靠服务商的信誉。直接向更上游、实际运营网络的公司购买，可以减少中间转手的环节，也少一些被冒充独享、重复出售的机会，但仍不能仅凭这一点确认独享。

如果特别在意独享，可以向阿里云、腾讯云、华为云等信誉良好的云服务商租一台服务器，申请只分配给你使用的公网 IP，再自行搭建代理。

这需要自己配置和维护，但可以绕开不透明的代理转售链。通过这种方式搭建的 IP，属于数据中心（Hosting）IP。

## 静态：使用期间不换地址

静态 IP 是在约定的使用条件下保持不变的地址；动态 IP 则可能在使用过程中变化。就像电话号码，静态是长期用同一个，动态则是以后可能换号。

真正通过家庭宽带上网的住宅 IP，通常采用动态分配，住宅代理服务的出口 IP 也常会变化。家庭路由器重连后，地址可能改变；提供代理的家庭设备关机或断网，这个出口也可能暂时不可用。如果你正在处理订单，就可能需要重新连接，网站也可能要求重新验证登录。

有些家庭宽带很久都不换地址，部分套餐也提供静态 IP，因此不能只凭“动态”就判断连接不稳定。对经常登录店铺后台的卖家来说，静态 IP 可以减少出口频繁变化带来的麻烦，但不保证连接永远不中断。

静态也不等于独享：一个固定地址，仍然可能被多个客户共用。

## 原生：登记位置和实际出口是否相符

“原生 IP”没有全行业统一的定义。服务商通常用它表示，地址的登记信息、地理位置查询结果，与实际出口所在的国家相符。

这有点像手机号归属地。你在上海办的号码，带到北京使用，归属地查询仍可能显示上海。IP 登记在哪里，与实际在哪里使用，也可能是两回事。

网站通常依靠 **IP 地理位置数据库**来判断访问来自哪里，相当于查一份 IP 归属地通讯录。但不同网站的数据来源不一定相同，也未必及时更新。

例如，你买的是美国出口，服务器也在美国，某个网站却仍把这批地址识别成另一个国家。页面显示的地区、语言或货币可能不对，网站也可能因为登录地点异常而要求额外验证。这是“非原生”地址可能带来的主要麻烦。

只看地址属于哪个 RIR 也不够。RIR 管理的是大片区域，不是某一个国家，登记信息不能证明服务器的位置。购买时可以参考几个 IP 查询网站，但更要看你使用的平台把它识别成哪里。

## ISP IP：运营商的地址，不一定在家庭宽带上使用

ISP 是 Internet Service Provider 的缩写，意思是互联网服务提供商。中国电信、中国联通、中国移动，就是常见的 ISP。

如果一个地址段登记在电信运营商名下，即使放在机房使用，查询 IP 时也可能显示这家运营商的名称。

运营商的地址既可以用于家庭宽带，也可以用于服务器。就像知道一个电话号码属于中国电信，也不能判断对方是在家里还是办公室使用。

在代理市场里，“ISP IP”经常指这类使用运营商地址、在服务器上运行的代理。有些商家称它为“静态住宅代理”，但访问不一定经过真实家庭宽带。

这类地址受到关注，是因为网站可能参考地址所属的公司和网络类型。与明显属于云机房的地址相比，运营商的地址在某些网站上可能更受信任。但网站还会看这个地址过去是否被滥用、是否被识别为代理，以及账号操作是否异常。查询结果中有运营商名称，不代表这个地址一定信誉良好、不会触发验证。

## 美刻建议用户把 IP 掌握在自己手里

美刻跨境浏览器（Merca Browser）建议用户自行购买或搭建代理，直接管理自己的 IP 服务，再接入美刻，而不是把 IP 和浏览器软件捆绑购买。

这样，你知道 IP 从哪里买来、由谁提供服务，服务商账号和续费也由自己管理。以后即使换用其他软件，也可以继续使用原来的 IP，不会因为 IP 绑在浏览器上而难以更换软件。

美刻不销售代理，也不绑定指定的网络服务商。我们不需要为了推销某种 IP 而回避它的局限，因此可以更坦诚地分享这些信息。
